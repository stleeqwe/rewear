# LEAFIT 화면설계서 v2.1

> **Screen Design v2.1 — Electric Garden**
> SWAP IS THE NEW SHOP — 전체 화면 구조 및 유저 플로우

---

## FLOW 1: 온보딩

> 스플래시 → 서비스 소개(3장) → 카카오/애플 로그인 → 동네 인증 → 첫 리프 지급. "Electric Garden" 다크 테마에서 밝은 테마로 전환.

| Screen ID | 화면 | 설명 |
|-----------|------|------|
| OB-01 | 스플래시 | Forest 배경 + LEAFIT 로고 + Leaf 아이콘 + 'SWAP IS THE NEW SHOP' 태그라인. 1.5초 후 자동 전환. |
| OB-02 | 서비스 소개 1/3 | '올리고. 받고. 스왑하고.' 옷→리프 교환 설명. |
| OB-03 | 서비스 소개 2/3 | '가격 따윈 없어.' 모든 옷 = 리프 1개 통일. |
| OB-04 | 서비스 소개 3/3 | '스왑할수록 레벨업.' 🌱→🪐 뱃지 시스템 소개. |
| OB-05 | 회원가입/로그인 | 다크→라이트 전환. 카카오 + Apple 소셜 로그인. |
| OB-06 | 동네 인증 | GPS 기반 위치 감지 + 수동 검색 변경 가능. |
| OB-07 | 첫 리프 지급 | 🍃 1 LEAF GET! 파티클 애니메이션 + 홈 유도. |

---

## FLOW 2: 홈 / 검색

> LEAFIT 로고 + 알림 + 리프 잔액 헤더. 카테고리 필터(전체/상의/하의/아우터/원피스) + 정렬(최신순/조회순/가까운순). 2열 그리드 + 스폰서드 아이템. FAB로 옷 등록 진입.

| Screen ID | 화면 | 설명 |
|-----------|------|------|
| H-01 | 메인 홈 | LEAFIT 헤더(로고+검색+알림+리프). 카테고리 칩 + 정렬. 2열 그리드 + 스폰서드 아이템. Lime FAB. |
| H-02 | 검색 화면 | 최근 검색어(개별/전체 삭제) + 인기 검색어 칩. 실시간 결과 매칭. |

---

## FLOW 3: 상세 페이지

> 상품 상세 — 사진 갤러리 + 판매자 뱃지 + 거래 방법 태그. 리프 부족 시 등록 유도. 내 아이템이면 수정/삭제. 판매자 프로필 화면.

| Screen ID | 화면 | 설명 |
|-----------|------|------|
| D-01 | 상품 상세 | 사진 갤러리(스와이프) + 상품 정보 + 판매자(뱃지) + 거래 방법 태그. [채팅하기] CTA. |
| D-02 | 리프 부족 | Smoke 카드로 '리프 없음 — 올려서 벌어 💪' 안내. [옷 올리러 가기] 유도. |
| D-03 | 내 아이템 | '이건 네 옷이야 ✌️' Forest 카드 + [수정하기] [삭제하기] 버튼. |
| D-04 | 판매자 프로필 | 뱃지 + 순환 횟수 + 등록 옷 3열 그리드. |

---

## FLOW 4: 옷 등록

> 4단계 등록: 사진(최소2장) + 정보 입력 → 미리보기 → AI 검수 → 합격(리프 GET) / 불합격(사유 안내).

| Screen ID | 화면 | 설명 |
|-----------|------|------|
| R-01 | Step 0: 정보 입력 | 사진(최소2장) + 카테고리/사이즈/상태 칩 + 설명 + 거래 방법(복수). |
| R-02 | Step 1: 미리보기 | 등록 전 미리보기. 상세 페이지와 동일 레이아웃으로 확인. 수정 링크. |
| R-03 | Step 2: AI 검수 | Lime 스피너 + '잠깐만, 확인하는 중 🔍'. 1.5~2초. |
| R-04 | Step 3: 합격 | '통과 ✅ LEAF GET!' Forest 다크 + 리프 카드(Smoke) + CTA. |
| R-05 | Step 4: 불합격 | 사유 카드 + 검수 기준(Smoke 카드) + [다시 올리기]. |

---

## FLOW 5: 채팅

> 채팅 목록 (거래 상태 뱃지: 채팅중/예약중/DONE) → 채팅방 (빠른 답장 + 약속 카드 + 안전 거래 안내) → 예약 → 거래 완료 + 평가.

| Screen ID | 화면 | 설명 |
|-----------|------|------|
| C-01 | 채팅 목록 | 아이템 썸네일 + 닉네임 + 마지막 메시지 + 상태 뱃지(채팅중/예약중/DONE) + 읽지않은 배지. |
| C-02 | 채팅방 (채팅중) | 고정 아이템 카드 + 안전 거래 안내 + 메시지 버블(Forest/White) + 빠른 답장 칩 + [예약하기]. |
| C-03 | 직거래 약속 카드 | 📍 장소 + '안전한 장소에서 만나 🤝'. 채팅 내 자동 삽입. |
| C-04 | 예약중 상태 | 📌 '예약 잠김' Butter 카드 + [거래 완료] Lime CTA + [거래 취소] Hot Coral. |
| C-05 | 거래 완료 | 'SWAP DONE 🤝' Forest 축하 카드 + 평가(👍/👎) + 48시간 신고 안내. |

---

## FLOW 6: MY 페이지

> 프로필 + 순환 뱃지 프로그레스(🌱→🪐) + 리프 지갑(Smoke 카드) + 4개 서브탭(내 옷장/교환한 옷/찜/기부) + 리프 내역 + 친구 초대.

| Screen ID | 화면 | 설명 |
|-----------|------|------|
| M-01 | MY 페이지 | 프로필(뱃지 칩) + 순환 뱃지 프로그레스(🌱→🪐) + 리프 지갑(Smoke/Neon Mint) + 내 옷장 탭 + 리프 내역 + 친구 초대. |
| M-02 | 교환한 옷 | 가져온 옷 리스트 + 원래 판매자 + 교환일. |
| M-03 | 찜 목록 | ♥ 누른 아이템 + 사이즈 + 판매자 동네. 탭→상세. |
| M-04 | 기부하기 | 🎁 '새 생명 ON' + [기부] 버튼 + 기부 현황 '총 N벌 보냈어 🔥'. |

---

## FLOW 7: 설정 / 알림

> 설정 (알림 토글/계정/고객센터) + 알림 목록 (검수/채팅/거래/기부 알림 유형) + 프로필 편집.

| Screen ID | 화면 | 설명 |
|-----------|------|------|
| S-01 | 프로필 편집 | 닉네임 변경 + 동네 변경 + [저장] CTA. |
| S-02 | 설정 | 알림 토글(채팅/거래/신상품) + 계정(로그아웃/탈퇴) + 고객센터 + 앱 정보. |
| S-03 | 알림 목록 | ✅검수/💬채팅/📌예약/🤝거래/🔥기부. 읽지않은 알림 초록 점. |
